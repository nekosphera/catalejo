# Security Policy

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities, exposed credentials, personal data or infrastructure secrets.

Use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, contact the repository owner privately through the contact method shown on the owner's GitHub profile and include:

- affected repository, component and version or commit;
- reproduction steps and impact;
- whether credentials or personal data may be involved;
- any suggested mitigation.

Please allow reasonable time for investigation before public disclosure.

## Scope

Security reports may cover application code, deployment configuration, authentication, authorisation, data transfer, policy enforcement, evidence integrity and dependency risks.

Public demonstrations and compatibility statements are not security certifications. Never submit real production credentials, certificates, tokens, health data or other personal data as test material.
